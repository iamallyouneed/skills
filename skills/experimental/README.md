# Experimental Skills

Unstable staging area. Breaking changes allowed without notice.

## Rules

- Each experimental skill lives in its own folder: `skills/experimental/<skill-name>/`
- Each skill must have `SKILL.md` (Claude instructions) + `README.md` (human overview)
- Promotion to top-level `skills/<skill-name>/` requires: stable behavior, docs, and `marketplace.json` registration

## Layout

```text
skills/experimental/<skill-name>/
├── SKILL.md
└── README.md
```
