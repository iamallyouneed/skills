# Double Shot Espresso

Strict two-pass workflow that never stops halfway. Maximum quality with only two user inputs.

- `SKILL.md`: instructions and metadata Claude loads
- `README.md`: this file — human-facing overview

## Status

Experimental. Breaking changes allowed without notice.

## When to use

User wants maximum quality with minimal back-and-forth — says double shot, two pass, confirm then redo, or asks for a perfect final result.

## How it works

1. **Phase 0 (silent)** — draft a plan, identify and prepare specialist skills via find-skills.
2. **Pass 1** — high-quality intermediate result (70–85%) with explicit assumptions, 1–3 points to confirm, and all required external connections listed.
3. **Pass 2** — after one user confirmation, re-execute fully and deliver a real finished product. No placeholders, no third question.
